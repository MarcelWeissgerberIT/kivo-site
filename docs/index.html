What do I need to get started?Was brauche ich zum Start?

A Mac with Apple silicon and macOS 26 or later. Use Kivo AI when enabled for your Kivo account, or install and sign in to the Codex CLI or Claude Code CLI. The provider’s desktop app alone may not be enough. Provider charges are separate. Local analysis needs Apple Intelligence; an approved, available agent can analyse instead. Kivo supports English and German.Einen Mac mit Apple silicon und macOS 26 oder neuer. Nutze Kivo-KI, wenn sie für dein Kivo-Konto freigeschaltet ist, oder installiere die Codex CLI oder Claude Code CLI und melde dich dort an. Die Desktop-App des Anbieters allein reicht nicht unbedingt. Anbieterkosten fallen separat an. Lokale Analysen brauchen Apple Intelligence; alternativ kann ein freigegebener, verfügbarer Agent analysieren. Kivo unterstützt Deutsch und Englisch.

Does everything stay on my Mac?Bleibt alles auf meinem Mac?

Project files are local by default. Work sent to Codex, Claude, Kivo AI or connected services is processed by those providers. You control the connections and permissions. Optional sync is separate.Projektdateien liegen standardmäßig lokal. Aufträge an Codex, Claude, Kivo-KI oder verbundene Dienste werden dort verarbeitet. Du bestimmst Verbindungen und Freigaben. Optionaler Sync ist separat.

What should I expect from the beta?Was kann ich von der Beta erwarten?

Start with a small app, website or tool. Kivo helps clarify the task, review supported results and improve them. Checks have limits; untested points stay visible. Try the result yourself before relying on it. This page’s walkthrough is an interactive example, not an AI session.Starte mit einer kleinen App, Website oder einem Tool. Kivo hilft beim Klären, Ansehen unterstützter Ergebnisse und Nachbessern. Prüfungen haben Grenzen; ungeprüfte Punkte bleiben sichtbar. Probiere das Ergebnis selbst aus, bevor du dich darauf verlässt. Der Ablauf auf dieser Seite ist ein interaktives Beispiel, keine KI-Sitzung.

Extra tools, on your termsWeitere Werkzeuge, nach deinen Regeln

Connect supported MCP services through your own Codex or Claude Code agent. Allow, ask or block each tool and set call limits per task. Kivo asks before exceeding a limit. The service sets its own prices; a call limit is not a spending limit.Verbinde unterstützte MCP-Dienste über deinen eigenen Codex- oder Claude-Code-Agenten. Erlaube einzelne Werkzeuge, lass nachfragen oder sperre sie und begrenze ihre Aufrufe pro Auftrag. Vor weiteren Aufrufen fragt Kivo. Die Preise bestimmt der Dienst; eine Aufrufgrenze ist kein Kostenlimit.
